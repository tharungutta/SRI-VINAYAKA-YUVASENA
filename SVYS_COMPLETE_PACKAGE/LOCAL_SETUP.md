# SRI VINAYAKA YUVA SENA — Local Version

This version does **not** ask for a Google Form URL or Google account connection.

### What is included
- Light, colorful Vinayaka-themed UI.
- Monthly collection is the first slide.
- Members are on a separate second slide.
- Mobile number appears beside every member name.
- Member list is dynamic; admin can add members later.
- Admin can add contributions and optional payment screenshots.
- Data is stored locally in the browser using `localStorage`.
- Admin can export the current data to an Excel-compatible `.xls` file.
- A starter Excel workbook is supplied separately as `SRI_VINAYAKA_YUVA_SENA_Tracker.xlsx`.

### Important
Because this is a local/browser version, data entered on one phone/computer is not automatically visible on another device. Use **Export Excel** to keep a backup/shareable record. If you later want every member's phone to see the same live data, a shared backend such as Google Sheets/Firebase/Supabase is required.
